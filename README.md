# cloverity.github.io

**🌐 Live:** https://cloverity.github.io/

Company GitHub Pages site.

## Case pages

`cases/` is generated by `tools/gen_cases.py` (`python3 tools/gen_cases.py`); edit the generator, not the HTML.
Hard rules for case pages:

- no JavaScript;
- no contact info;
- no links outside `cases/`;
- no client or employer names;
- no years, except the `© 2026 Cloverity Software` footer (explicit exemption from the task doc);
- every number carries a basis label.

`cases/*.html` are generated: edit `tools/gen_cases.py`, run `python3 tools/gen_cases.py`, and commit the generator and the regenerated HTML together.
